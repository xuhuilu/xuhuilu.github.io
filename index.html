01 / RESEARCH

Research grounded in
structural evidence

My research connects software understanding with the evidence needed to assess reliability. Structure is not just a representation—it is a way to reason about software, its changes, and the properties those changes should preserve.

01AI × SOFTWARE ENGINEERING

Reliable software engineering & AI agents

AI agents for software development, automated program repair, and software testing. I study how agents can use structural and repository evidence to make changes that are not only plausible, but verifiable.

  • AI AGENTS
  • PROGRAM REPAIR
  • SOFTWARE TESTING
02STRUCTURE × COMPREHENSION

Repository-level software comprehension

Function-call graphs, structural representations, and retrieval-augmented generation for understanding software. My goal is to connect the right code context with the questions developers and agents need to answer.

  • CALL GRAPHS
  • RAG
  • CODE COMPREHENSION
03ANALYSIS × ASSURANCE

Program analysis & change validation

Specification discovery and analysis of the properties that software changes should preserve. I am interested in validation that explains why a change is trustworthy, rather than treating a passing result as the whole answer.

  • PROGRAM ANALYSIS
  • SPECIFICATIONS
  • CHANGE VALIDATION
