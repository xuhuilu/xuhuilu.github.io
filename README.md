# Xuhui Lu — Academic Homepage

Personal academic homepage: https://xuhuilu.github.io/

## Update the website

Edit `index.html` for biography, publications, research, and experience. Replace `cv.pdf` to update the CV. Changes pushed to the `main` branch automatically redeploy through GitHub Pages. No build dependencies are required.

## Local preview

Open `index.html` in a browser. Keep `cv.pdf` in the same directory.
